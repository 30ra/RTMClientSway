# バージョン番号

正式版は`MAJOR.MINOR.PATCH`、開発版は次の正式版番号に`-dev.N`を付けます。

- 互換性を壊す変更：MAJORを増やし、MINOR・PATCHを0に戻す。
- 機能追加：MINORを増やし、PATCHを0に戻す。
- 不具合修正・内部整理：PATCHを増やす。
- 同じ次期版の開発更新：`dev.N`のNを増やす。正式版になるまで正式版番号は変えない。
- 正式リリース：`-dev.N`を外す。

MOD内のバージョン、mcmod.info、JAR名を揃えます。タグを作成する場合は`v`を付けた同じ番号を使います。開発版の更新だけではReleaseを作成しません。公開READMEの機能・設定説明は正式リリース後に更新し、開発中の説明は開発用資料へ記載します。既存JARの内容を別の内容で上書きしません。

開発版JARはGit管理対象外の`build/private-dist/`へ出力します。公開リポジトリ、Release、公開Actionsアーティファクトには置きません。ソースコードは公開されているため、第三者によるビルドを禁止・防止するものではありません。

正式リリース`v1.0.0`・`v1.0.1`およびそのタグ・添付ファイルは変更しません。過去のGitコミットも書き換えません。

旧`1.1.0-dev`は複数回上書きされていたため、コミットごとに分離して再ビルドしました。dev.1とdev.2は上記コミットのソースで、MODのバージョン・mcmod.info・出力JAR名だけを統一番号に変更しています。dev.3は現在のソースです。旧`1.1.1-dev`は独立した機能更新ではないためdev.3へ統合します。

未リリースJARは現在の公開ツリーから取り下げています。ローカルのバックアップと過去のGit履歴には残っています。フォーク・過去のコミット・取得済みコピーを含む完全回収はできません。歴史的ソースからの再ビルドもゲーム内検証を意味しません。
